# Hybrid Azure Infrastructure Lab

## Project Overview

This project demonstrates the design, deployment, and administration of a hybrid Microsoft infrastructure by integrating an on-premises Windows Server 2022 Active Directory environment with Microsoft Azure.

The lab focuses on implementing core Azure infrastructure services while extending an existing Active Directory domain into a hybrid cloud environment. Throughout the project, Azure networking, identity, storage, monitoring, backup, and automation are configured using Microsoft best practices.

This repository serves as a practical portfolio showcasing hybrid cloud administration skills for Systems Administration and Azure Administration roles.

---

## Project Goals

- Design a hybrid infrastructure architecture
- Configure secure hybrid networking
- Deploy Azure infrastructure resources
- Integrate Microsoft Entra ID with on-premises Active Directory
- Deploy and manage Azure Virtual Machines
- Configure Azure Files
- Configure Azure Backup
- Implement Azure Monitor
- Configure Azure Update Manager
- Automate administration using Azure PowerShell
- Document deployment, validation, and troubleshooting
